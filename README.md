# ze-dev

An open source project to design a game development studio economy simulation, beginning around 1950 and following the changing history of computer games. The planned game targets Linux and Windows, uses Godot, and favors C# for game logic.

The project is currently in the design stage. The [wayfinder map](https://github.com/marcodinf-a11y/ze-dev/issues/1) tracks open design decisions. Its [historical research](.scratch/studio-simulation/research/historical-timeline-model.md) explains why a 1950 opening differs from a later consumer PC game market.

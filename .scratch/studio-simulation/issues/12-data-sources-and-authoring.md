## Requirement

Game data must come from configuration files or databases rather than being hardcoded. Mod support must be designed in from day one.

## Question

Which game data belongs outside code, which configuration formats or databases should supply it, and how should data be authored, identified, referenced, loaded, versioned, and validated? Distinguish authored content from saved simulation state and settle the boundary between configurable data and simulation rules.

## Requirement

The game must be mod friendly from day one.

## Question

What should mods be able to add or change initially, and what loading and compatibility contract supports that? Decide whether support covers data, assets, or executable behavior, and how discovery, dependencies, load order, overrides, conflicts, validation, and save compatibility should work.

## Context

Build on [Data sources and authoring](12-data-sources-and-authoring.md). Do not assume that executable mods are required or that a configuration format or database has already been chosen.
